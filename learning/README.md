## 📚 学习路线（第2轮 - 深化学习）

### 第1次 ✅ 数据库 MongoDB 基础
- 安装、Docker 部署、连接
- CRUD 操作
- Schema 模型定义
- Mongoose ODM
- 嵌套文档、数组查询
- 实战：用户管理 API

### 第2次 ✅ Express 进阶
- 路由模块化（Router）
- 错误处理中间件
- CORS 跨域
- JWT 用户认证
- 项目结构最佳实践
- **示例：** `examples/express-advanced/`

### 第3次 ✅ TypeScript 进阶
- 泛型（Generics）
- 装饰器（Decorators）
- 类型守卫（Type Guards）
- 工具类型（Utility Types）
- 条件类型、映射类型
- **示例：** `examples/typescript-advanced/`

### 第4次 ✅ Node.js 实战项目
- 待办事项 API
- 用户认证
- 数据库集成
- RESTful API 设计
- 筛选、排序、分页
- **示例：** `examples/todo-api/`

### 第5次 ✅ 部署基础
- PM2 进程管理
- Nginx 反向代理
- Docker 容器化
- **示例：** `examples/deployment-basics/`

### 第6次 ✅ Redis / GraphQL
- Redis 缓存策略（Cache-Aside、LRU、穿透/击穿/雪崩）
- GraphQL API 设计（类型定义、Resolver、Apollo Server）
- **示例：** `examples/redis-graphql-demo/`
- **笔记：** `notes/2026-03-31-redis-graphql.md`
