## 1. 变量声明：let / const / var

```js
// const - 不可重新赋值，适合常量
const PI = 3.14159;

// let - 可以重新赋值，块级作用域
let count = 0;
count = count + 1;

// var - 函数作用域（已不推荐使用）
var oldStyle = "尽量避免";
```

**关键区别：** `const` 声明的对象引用不可变，但属性可以修改；`let` 声明的变量可以随时重新赋值。

## 2. 函数：箭头函数 vs 普通函数

```js
// 普通函数
function add(a, b) {
  return a + b;
}

// 箭头函数（更简洁）
const add = (a, b) => a + b;

// 带函数体的箭头函数
const greet = (name) => {
  const message = `你好，${name}！`;
  return message;
};

console.log(greet("大鱼")); // 你好，大鱼！
```

**TypeScript 版本：**
```ts
// 类型注解
const add: (a: number, b: number) => number = (a, b) => a + b;

function greet(name: string): string {
  return `你好，${name}！`;
}
```

## 3. 数组与对象操作

```js
// 数组
const fruits = ["苹果", "香蕉", "橙子"];

// map - 映射/转换
const upperFruits = fruits.map(f => f.toUpperCase());
console.log(upperFruits); // ["苹果", "香蕉", "橙子"] → ["苹果", "香蕉", "橙子"]

// filter - 过滤
const nums = [1, 2, 3, 4, 5, 6];
const evens = nums.filter(n => n % 2 === 0);
console.log(evens); // [2, 4, 6]

// 对象解构
const person = { name: "大鱼", age: 18, city: "上海" };
const { name, age } = person;
console.log(name, age); // 大鱼 18

// 数组解构
const [first, second] = fruits;
console.log(first, second); // 苹果 香蕉
```

## 4. Promise 与 async/await（异步编程）

```js
// Promise - 解决回调地狱
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve("数据加载成功！");
    }, 1000);
  });
}

// async/await - 更易读的异步写法
async function main() {
  console.log("开始加载...");
  const result = await fetchData();
  console.log(result); // 1秒后输出：数据加载成功！
  console.log("加载完成");
}

main();
```

**TypeScript 版本：**
```ts
function fetchData(): Promise<string> {
  return new Promise((resolve) => {
    setTimeout(() => resolve("数据加载成功！"), 1000);
  });
}

async function main(): Promise<void> {
  const result = await fetchData();
  console.log(result);
}
```

## 5. TypeScript 类型系统

```ts
// 基本类型
const name: string = "大鱼";
const age: number = 18;
const isStudent: boolean = true;

// 数组
const scores: number[] = [90, 85, 92];
const names: Array<string> = ["苹果", "香蕉"];

// 接口 - 定义对象结构
interface User {
  id: number;
  name: string;
  email?: string; // 可选属性
  readonly createdAt: Date; // 只读属性
}

const user: User = {
  id: 1,
  name: "大鱼",
  createdAt: new Date(),
};

// 联合类型
type Status = "pending" | "success" | "error";
const status: Status = "success";

// 泛型
function identity<T>(arg: T): T {
  return arg;
}
const num = identity<number>(42);
const str = identity("hello");
```

## 6. 类（Class）

```ts
class Animal {
  name: string;
  
  constructor(name: string) {
    this.name = name;
  }

  speak(): void {
    console.log(`${this.name} 发出声音`);
  }
}

class Dog extends Animal {
  breed: string;

  constructor(name: string, breed: string) {
    super(name); // 调用父类构造函数
    this.breed = breed;
  }

  speak(): void {
    console.log(`${this.name} 汪汪汪！`);
  }

  fetch(): void {
    console.log(`${this.name} 去捡球！`);
  }
}

const dog = new Dog("旺财", "金毛");
dog.speak();  // 旺财 汪汪汪！
dog.fetch();   // 旺财 去捡球！
```
