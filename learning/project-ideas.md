# 项目灵感列表 🦞

**创建日期：** 2026-03-31  
**目的：** 适合大鱼的编程实战项目

---

## 1. 📋 个人待办事项 App（Todo List）

**技术栈：** TypeScript + React（前端）+ LocalStorage（数据存储）  
**难度：** ⭐ 入门  
**简介：** 一个简洁的待办事项管理应用，支持添加、完成、删除、筛选任务。

**为什么适合：**
- 需求简单，1-2 天可以做出原型
- 涉及 React 状态管理、组件化思维
- 可以对接企业微信待办（用上现成工具！）

---

## 2. 🌤️ 天气信息小工具

**技术栈：** TypeScript + Node.js（后端）+ 天气 API  
**难度：** ⭐⭐ 入门~进阶  
**简介：** 每天定时抓取天气信息，推送给大鱼，支持设置多个城市。

**为什么适合：**
- 结合现有微信推送能力
- 练习异步编程（async/await）
- 理解 API 调用和数据处理

---

## 3. 📊 每日打卡统计 Bot

**技术栈：** TypeScript + 企业微信机器人 / 飞书机器人  
**难度：** ⭐⭐ 入门~进阶  
**简介：** 记录每日学习/运动/喝水等习惯打卡，生成统计图表和周报。

**为什么适合：**
- 和日常工作流结合，实用性强
- 练习数据存储（JSON 文件或 SQLite）
- 理解定时任务和消息推送

---

## 4. 📁 文件整理助手

**技术栈：** TypeScript + Node.js（fs 模块）  
**难度：** ⭐⭐ 中等  
**简介：** 自动按日期、按文件类型整理指定目录下的文件，生成整理报告。

**为什么适合：**
- 解决真实痛点（桌面乱、下载目录乱）
- 练习 Node.js 文件系统操作
- 了解正则表达式应用

---

## 5. 🤖 AI 助手接口聚合服务

**技术栈：** TypeScript + Node.js + Express + 多 AI API  
**难度：** ⭐⭐⭐ 进阶  
**简介：** 一个统一接口，支持同时向多个 AI（OpenAI、Claude、Gemini）发送请求并对比回答。

**为什么适合：**
- 练习 API 设计（RESTful）
- 深入理解异步并发处理
- 对接现有 AI 能力，了解 API 网关概念

---

## 建议优先级

| 优先级 | 项目 | 理由 |
|--------|------|------|
| 🥇 | 个人待办 App | 最简单、最快出成果、建立信心 |
| 🥈 | 天气小工具 | 实用、练习异步、结合推送 |
| 🥉 | 文件整理助手 | 解决实际问题、练习 Node.js |

---

> 💡 提示：从小项目开始，不要一上来就做复杂的。先做出能用的版本，再迭代改进！
