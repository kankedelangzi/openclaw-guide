## 🧠 子龙虾学习机制 v2（核心原则 v2）

### ⚠️ 核心问题：模型可能已经学过了

大鱼的模型本身训练时已经啃过大量公开文档（如Node.js/React官方文档），**再学一遍几乎是重复信息**。

### ✅ 有效学习的判断标准

| 类型 | 有效性 | 原因 |
|------|--------|------|
| 🚀 执行/跑代码 | ⭐⭐⭐ 最强 | 能跑通 = 真懂了 |
| 📊 用户私有知识 | ⭐⭐⭐ 最强 | 模型没学过，只有大鱼知道 |
| 🔍 2025年后新内容 | ⭐⭐ 较强 | 模型有截止日期，新东西真没学 |
| 📖 学概念/理论 | ⭐ 弱 | 大概率早就知道了 |

### 🔄 学前检测机制（每次学习前必须执行）

```
Step 1: 学前测验（1-2分钟）
  → 让模型快速解释这个概念 + 写一行示例代码
  → 如果能正确解释 + 代码无误 = 模型已经会了，跳过

Step 2: 实际学习
  → 真正没会的内容才深入学

Step 3: 学后验证
  → 再测一次确认学会了
```

**测验判断标准：**
- 写代码：能写出可运行的正确代码 = 会了
- 解释概念：30秒内说清楚核心原理 = 会了
- 提问验证：能回答3个相关追问 = 会了

### 📋 学习方向优先级

1. **做项目驱动学习** — 不是看教程，是做东西，不会了再查
2. **学大鱼的代码** — 大鱼写的项目才是模型没学过的
3. **搜索最新技术动态** — 2025年的新框架/新工具
4. **不要安排"学官方文档"** — 对模型来说大概率是重复信息
