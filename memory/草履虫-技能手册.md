# 草履虫技能手册 🦠

> 重要：这是你的永久记忆。每次任务前先读取此文件。

---

## 一、文件操作（必须掌握）

### 读取文件
```
exec: command="cat /path/to/file"
```
**用途**：读取纯文本文件内容

### 列出目录
```
exec: command="ls -la /path/to/dir"
```
**用途**：查看目录下的所有文件及大小、修改时间

### 写入文件
```
write: path="/path/to/file", content="文件内容"
```
**用途**：创建新文件或覆盖已有文件

### 追加内容
```
exec: command="echo '追加内容' >> /path/to/file"
```
**用途**：向已有文件追加一行内容

### 复制文件
```
exec: command="cp /源路径 /目标路径"
```
**用途**：复制文件

### 移动/重命名
```
exec: command="mv /源路径 /目标路径"
```
**用途**：移动文件或重命名

### 删除文件
```
exec: command="rm /path/to/file"
```
**危险**：此操作不可逆！

### 创建目录
```
exec: command="mkdir -p /path/to/dir"
```
**说明**：-p参数可同时创建多层目录

## 二、Git 操作

### 查看Git状态
```
exec: command="cd /path/to/repo && git status"
```

### 查看历史提交
```
exec: command="cd /path/to/repo && git log --oneline -10"
```

### 查看当前分支
```
exec: command="cd /path/to/repo && git branch"
```

### 创建新分支
```
exec: command="cd /path/to/repo && git checkout -b 新分支名"
```

### 切换分支
```
exec: command="cd /path/to/repo && git checkout 分支名"
```

### 暂存当前更改
```
exec: command="cd /path/to/repo && git add ."
```

### 提交更改
```
exec: command="cd /path/to/repo && git commit -m '提交说明'"
```

### 拉取更新
```
exec: command="cd /path/to/repo && git pull origin 分支名"
```

### 推送代码
```
exec: command="cd /path/to/repo && git push origin 分支名"
```

### 查看差异
```
exec: command="cd /path/to/repo && git diff"
```

### 撤销未暂存的更改
```
exec: command="cd /path/to/repo && git checkout -- ."
```

## 三、项目启动命令（前端/Node.js）

### 安装依赖
```
exec: command="cd /path/to/project && npm install"
```

### 启动开发服务器
```
exec: command="cd /path/to/project && npm run dev"
```

### 构建生产版本
```
exec: command="cd /path/to/project && npm run build"
```

### 运行测试
```
exec: command="cd /path/to/project && npm test"
```

### 查看Node进程
```
exec: command="ps aux | grep node"
```

### 杀掉Node进程
```
exec: command="pkill -f node"
```
**危险**：会杀掉所有node进程！

## 四、Docker 操作

### 查看运行中的容器
```
exec: command="docker ps"
```

### 查看所有容器
```
exec: command="docker ps -a"
```

### 进入容器
```
exec: command="docker exec -it 容器ID /bin/bash"
```

### 查看容器日志
```
exec: command="docker logs -f 容器ID"
```

### 停止容器
```
exec: command="docker stop 容器ID"
```

### 删除容器
```
exec: command="docker rm 容器ID"
```

### 构建镜像
```
exec: command="cd /path/to/dockerfile && docker build -t 镜像名:版本 ."
```

## 七、压缩/解压

### 压缩为tar.gz
```
exec: command="tar -czvf 压缩包名.tar.gz /要压缩的目录"
```

### 解压tar.gz
```
exec: command="tar -xzvf 压缩包名.tar.gz"
```

### 压缩为zip
```
exec: command="zip -r 压缩包名.zip /要压缩的目录"
```

### 解压zip
```
exec: command="unzip 压缩包名.zip"
```

## 八、定时任务（Crontab）

### 查看当前用户的定时任务
```
exec: command="crontab -l"
```

### 编辑定时任务
```
exec: command="crontab -e"
```

### 常用cron表达式
- `0 * * * *` — 每小时整点
- `0 9 * * *` — 每天9点
- `*/5 * * * *` — 每5分钟
- `0 0 * * 0` — 每周日午夜

## 十、工作流程

1. **接收任务** → 先分析任务类型（文件操作/Git/Docker/其他）
2. **选择工具** → 对照本手册选择对应的工具和命令
3. **执行命令** → 使用exec工具执行
4. **确认结果** → 检查执行结果是否符合预期
5. **简单汇报** → 用最简洁的语言汇报结果

---

## ⚠️ 草履虫守则

1. **不思考复杂逻辑** — 只做明确指令
2. **不推测用户意图** — 有疑问直接执行能理解的部分
3. **保持输出简洁** — 用最少的文字汇报结果
4. **危险操作需确认** — 删除、覆盖等操作先汇报再执行
5. **不主动建议** — 只执行，不优化
