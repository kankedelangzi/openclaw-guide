# 龙虾任务：技能沉淀循环 🦞

> 学习不只是记住，**能用才是真的会**。

---

## 核心原则

**每次学习新技术/工具/命令后，必须问自己：**
> "这个能写成草履虫能用的脚本吗？"

---

## 技能沉淀流程

```
学习新内容
    ↓
识别可脚本化的操作（文件操作/Git/Docker/进程管理等）
    ↓
编写脚本到 /workspace/skills/<技能名>/scripts/
    ↓
更新 /workspace/skills/<技能名>/SKILL.md
    ↓
更新草履虫技能索引（/workspace/memory/草履虫-技能索引.md）
    ↓
报告完成
```

---

## 必须沉淀的内容

1. **系统操作** - 文件/目录/压缩/解压
2. **开发工具** - npm/git/docker/pm2/redis-cli
3. **框架命令** - next/build, react/start, node/serve
4. **数据库** - mongo/redis/postgres 常用命令
5. **部署脚本** - nginx/systemctl/supervisor
6. **监控日志** - tail/grep/awk 组合命令

---

## 技能存放规范

```
/workspace/skills/<技能名>/
├── SKILL.md           # 技能说明（必填）
└── scripts/
    ├── script1.sh     # 脚本（可选多个）
    ├── script2.sh
    └── ...
```

---

## 草履虫技能索引

每个新技能创建后，更新索引文件：
`/workspace/memory/草履虫-技能索引.md`

格式：
```
## 已创建技能

| 技能名 | 功能 | 脚本 |
|--------|------|------|
| 文件整理 | 合并/统计/重命名 | merge, count |
| Git操作 | status/commit/pull | status, commit |
```

---

## 示例

### 场景：子龙虾学了 Docker

**学习产出**：
- 笔记：Dockerfile编写、多阶段构建
- 代码：production.Dockerfile

**技能沉淀**：
- 脚本：`docker-build.sh` - 构建生产镜像
- 脚本：`docker-run.sh` - 运行容器
- 脚本：`docker-logs.sh` - 查看日志
- SKILL.md：描述用法

**结果**：
草履虫现在可以执行 `docker-build.sh` 构建镜像，无需理解Docker原理。

## 优先级

| 优先级 | 内容 | 例子 |
|--------|------|------|
| P0 | 文件操作 | cp/mv/rm/tar |
| P0 | Git操作 | add/commit/push/pull |
| P1 | 开发栈 | npm run build/dev |
| P1 | Docker | build/run/logs |
| P2 | 进程管理 | pm2/nginx |
| P2 | 数据库 | mongo/redis-cli |

- [ ] 已经更新草履虫技能索引了吗？
