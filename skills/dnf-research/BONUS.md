## 📊 DNF 70版本加成系统

| 类别 | 子系统 | 70版本特征 |
|------|--------|-----------|
| **装备** | 异界套装(E2/E3) | 技能等级+2~3，伤害+10~20% |
| **装备** | CC套（宫廷套装） | 百分比/固伤加成，职业专属 |
| **装备** | 远古套装 | 基础属性加成，无特殊机制 |
| **装备** | 粉装/史诗 | 独立数值加成，无黄白字 |
| **宝石** | 属性石 | 力量/智力/属强宝石 |
| **宝石** | 强化石 | 武器/防具强化等级 |
| **时装** | 上衣/下装 | 力量/智力/HP/MP |
| **时装** | 头部/帽子 | 施放速度/物理/魔法暴击 |
| **时装** | 脸部/胸部 | 攻击速度/独立攻击 |
| **时装** | 腰带/鞋子 | 回避率/移动速度 |
| **其他** | 宠物 | 力量/智力/属强加成 |
| **其他** | 称号 | 全属性/特定属性加成 |
| **其他** | 勋章/徽章 | 属性石镶嵌位 |

### 加成计算原则（70版本）
```
最终伤害 = 基础伤害 × 装备加成 × 宝石加成 × 时装加成 × 其他加成
```
- 各乘区独立相乘
- 同类加成内部相加，不同类相乘
- **无黄白字叠加**（80版本才有）

| **角色** | 角色等级 | 基础属性成长 |
| **角色** | 天赋系统 | 解锁特殊能力/加成 |

| **其他** | 羁绊系统 | 角色组合加成 |

### 加成计算原则（向僵尸开炮）
```
最终伤害 = 基础攻击 × 武器加成 × 技能加成 × 装备加成 × 角色加成 × Buff加成
```
- 武器升级是核心加成来源
- 技能等级影响显著（主动技能倍率提升）
- 套装效果提供额外乘区

## 📖 宝石加成系统（D3 - 2026-05-29 完成）

### 属性石数值表（70版本）
| 等级 | 力量/智力 | 属性强化 | 暴击率 |
|------|-----------|----------|--------|
| 一级 | +8 | +10 | +1% |
| 二级 | +16 | +20 | +2% |
| 三级 | +24 | +30 | +3% |
| 四级 | +32 | +40 | +4% |
| 五级 | +40 | +50 | — |
| 六级 | +48 | +60 | — |

### 收益计算公式
```
力量收益（百分比技能）：增幅 = (1 + 新增力量/250) / (1 + 原力量/250) - 1
属性强化收益：增幅 = (220 + 新增属强) / (220 + 原属强) - 1
暴击期望：暴击率 × 1.5 + (1 - 暴击率) × 1.0 = 1 + 0.5 × 暴击率
```

### 强化等级收益表（70版本）
| 等级 | 攻击力加成 | 成功率 | 失败后果 |
|------|-----------|--------|----------|
| +0→+5 | +2%~10% | 100% | 无 |
| +5→+6 | +12% | 90% | 降级至+4 |
| +6→+7 | +15% | 80% | 降级至+5 |
| +7→+8 | +18% | 70% | 降级至+6 |
| +8→+9 | +22% | 60% | 降级至+7 |
| +9→+10 | +26% | 50% | 降级至+8 |
| +10→+11 | +30% | 40% | 降级至+9 |
| +11→+12 | +36% | 30% | 降级至+10 |
| +12→+13 | +42% | 20% | 降级至+11 |

### 职业差异化建议
- **百分比职业**：优先力量宝石 + 高强化武器（+9~+12）
- **固伤职业**：优先属性强化宝石，强化武器收益低
- **混合职业**：2力量 + 2属强宝石，强化至+7~+9

## 📖 宠物/称号/勋章加成系统（D5 - 2026-05-30 完成）

### 加成乘区结构
```
最终伤害 = 装备乘区 × 宝石乘区 × 时装乘区 × 宠物乘区 × 称号乘区 × 勋章乘区
```
- 各乘区独立相乘，同类加成内部相加
- 宠物/称号/勋章为独立乘区，与装备/宝石不冲突
