# DNF 70版本伤害公式分析

## ⚠️ 版本锁定：只研究 70版本末期

## 防御减伤公式
```
final = base × 300 / (300 + defense)
```
- 70版本通用公式，适用于所有职业
- 300 是基准防御值

## 属强公式
```
bonus = 1 + (element / 220)
```
- 每 22 点元素攻击 = +10% 对应属性伤害
- 无后续版本套装加成

## 暴击伤害
- 基础暴击：150%
- 无额外暴伤装备（80版本才有）

## 固伤公式
```
fixed = base × (1 + independent / 250) × skill_rate
```
- `independent`：独立攻击力
- `skill_rate`：技能倍率

## 主属性加成
```
(1 + str/int ÷ 250)
```
