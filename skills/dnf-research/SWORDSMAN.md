## 📐 伤害计算公式

```
百分比最终伤害 = 物理攻击 × 技能倍率 × (1 + 力量/250) × 防御减伤 × 暴击期望

破极兵刃加成 = 基础物理攻击 × 1.30
武器强化：+12 → ×1.36，+13 → ×1.42
```

## 核心任务成果摘要

### 任务17：破极兵刃机制 ✅
- 物理攻击+30%（Lv10），CD 60s，持续30s
- 四种武器精通收益率均为+30%
- 覆盖率50%，可卡CD刷新接近100%
- **与暴走对比**：高频低幅 vs 低频高幅
- ⚠️ 武器精通仅提供武器基础物理攻击差异，无技能倍率加成

### 任务19：CC套加成 ✅ v13完成
- **6件套属性**：力量+310，物理攻击+110，独立攻击+120，暴击+3%
- **阈值机制**：1~5件套装效果不生效，仅6件激活
- **百分比收益**：+42.4%（力量+36.5% × 物理攻击+2.3% × 暴击+2.0%）
- **破极兵刃协同**：物理攻击额外+110（2600→2710），系数比收益+2.3%
- **推荐搭配**：E2剑舞6件 + CC套2件（上衣+下装技能加成+1）
- **审核修正**（v13）：
  - 力量收益：+27.2% → +36.5%
  - 物理攻击收益：+4.2% → +2.3%（完整系数比公式）
  - 百分比综合：+45.1% → +42.4%
  - 审核通过率：98.0%（50/51项通过）

### 任务20：粉装/史诗独立加成 ✅ v1.0（审核100%通过）
- **独立加成机制**：粉装/史诗提供独立乘区加成，与面板属性独立相乘，无收益递减
- **粉装全套收益**：武器+4% + 项链+3% + 戒指+3% + 手镯+2% = **+13%**
- **史诗全套收益**：武器+10% + 项链+6% + 戒指+5% + 手镯+4% = **+25%**
- **史诗领先粉装**：+12个百分点（近2倍）
- **百分比通用**：独立加成对百分比流派收益相同，不受伤害类型影响
- **线性叠加**：各部位独立加成直接相加，不存在边际收益递减
- **毕业推荐**：武器天选之剑·格朗（+10%）+ 灵魂之源项链（+6%）+ 安徒恩史诗戒指（+5%）+ 悲鸣史诗手镯（+4%）
- **输出文件**：`notes/bonus-system/dnf-epic-premium-bonus.html` | 审核报告：`review-task20-v1.md`
